# File-aligned research explorer: local development checks

Checked on macOS/arm64, Python 3.9.6, with the official dsh packages at
`0.2.2-rc.1` under Node 24.11.0. These checks used synthetic projects and
simulated operator acknowledgments. No model API or GPU training was used.

| Check | Observed result | Scope |
|---|---|---|
| Python behavior suite | 84 tests passed | Existing runtime plus 18 exploration behavior tests |
| Browser behavior | 11 checks passed, zero page errors | A fresh synthetic Git project in Google Chrome through Playwright |
| dsh plugin | Passed | Actual Cordis registry and native tool executor, with controller subprocess calls |
| Official dsh CLI | Patch composed successfully | `headless --patch ... --dump-config`; no agent/model turn |
| Wheel | Built and installed; resources present | Python modules, HTML/CSS/JS, and external dsh plugin included |
| Large code diff | Correctly marked unavailable | 1.32 MB synthetic source; no partial patch represented as complete |

Exploration checks cover pending/exact boundary acknowledgment, source/data drift,
unresolved file permissions, Git merge lineage, origin mirrors, unknown metrics,
review/evidence binding, stored code patches, credential/symlink exclusions,
maximize/minimize stagnation, sibling preservation, explicit reopening, retained
reservation costs, stale requests, isolated CLI workspaces, read-only preapproval
discussion, unversioned projects, and cancellation of the owned CLI process.

Browser checks cover tree/ghost states, code diff, persistent review, JSON export,
manual disable/enable, dragging a node document into discussion, metric/lineage/file
layouts, draft invalidation, CSRF rejection, a blocked continuation before approval,
and a permitted read-only discussion before approval.

The dsh check verifies registered schemas, controller reads, a node context packet,
rejection of unsupported self-approval/enable actions, and execution through the
real native tool pipeline. It is not a real-model agent behavior check. The
dispatch lifecycle tests use a stub CLI, not an invented native-agent session.

The viewer's height-ranked records are imported/reported observations, not runtime
statistical acceptance. Auto-close is a search heuristic. Live dsh account/model
configuration, real training-project adapters, refactor equivalence, scientific
improvement and production isolation still require their own validation.

Reproduction commands and authority boundaries are in
[the explorer guide](../exploration-harness.md). Raw local test/browser evidence
and failure logs remain outside this repository; no private project data was
copied into the published validation note.
